Aurey Wallet MCP

Self-hosted MCP server for EVM wallet tools via 1Claw Intents—balances, swaps, and signing without private keys in chat.

Install Cursor Hermes Claude OpenClaw llms.txt GitHub

Quick install

curl -fsSL https://agentic-pantheon.github.io/aurey-mcp/install.sh | bash
aurey-setup --host cursor   # or: hermes | claude | openclaw

Run aurey-setup in your terminal. Never paste 1ck_ or ocv_ keys into LLM chat.

Choose your host

Hermes

aurey-setup --host hermes
hermes mcp test aurey-wallet

Cursor

aurey-setup --host cursor

Restart Cursor or reload MCP in Settings.

Claude Desktop

aurey-setup --host claude

OpenClaw

aurey-setup --host openclaw
